Objective

Use a ball to knock various toys off the edge of the table. However, if the ball goes off the table, you lose points. When all the toys are off of the table, the game moves to the next level.

How it works

In this game, you don't control the ball directly but rather apply invisible forces using your mouse to make the ball move. Gravity, friction, and momentum take care of the rest.

Beginner games provide some aides to get you familiar with the game. For example, a magic fence is used to keep the ball on the table while allowing toys to be pushed through it. The beginning games are not timed.

As you advance to higher games, there are more challenges: No more fences. More and different toys. Wind will be introduced on some games. Higher games are timed. And the countdown can sometimes be short.

Bonus points can be had for certain maneuvers on a toy. Some toys have to be dislodged from the walls by hitting them with the ball.

How to Play

Press the play button. This is a full screen game. When you leave the game (escape key, close button, or X on the keyboard) or, the game times out or, you lost your balls, this page reappears.

When toys drop onto the table, some may fall off of the table without your assistance. You'll get credit for them in any case. On the other hand, when a ball falls off the table, it will cost you points.

Check the scoreboard for the number of balls available on each game level. If too many balls fall off the table: Game Over.

Balls and toys fall onto the table from random locations. So, no two games are exactly alike.

If a ball does fall off the table, you can recover it by using the space bar and mouse to bounce it back up. But, you'll have to be quick. Scoring only occurs when a ball or toy falls down to the floor.

Use the O key (for "overhead") if you need a quick look at the table from the top down. In some cases, a toy could be hiding behind a barrier.

Scoring

Each toy that hits the ground adds points. Some toys, such as the black disk, subtract points unless you've turned it white. If you get all of the toys on the ground before time runs out, you get points for completing a level.

The scoreboard shows the points scored for the current level and the total score for the game. If the game clock runs out or you run out of balls in a given level, then the total score for the game is zero. Harsh.

Your last and highest score for each game level is shown. If you login, upper right icon, I'll keep your scores in the cloud for subsequent sessions.

User actions while in the game

press the X key or click the Close button (upper right corner) to exit the game.

Push the ball around by holding down the left mouse button and moving the mouse.

You can also use the Arrow keys or 4, 8, 6, 2 on the keypad to push the ball around.

Use the Space Bar or keypad 5 to bounce the ball.

Cheat Codes

Press the G key to start a new game.

Press the N key to go to the next level. If the next level is timed, the timer starts now.

Press the R key to replay the same level.

Hardware Requirements

Unlike many 3d games that require a beefy GPU, the Holy Balls game uses relatively simple toy patterns like blocks, cones, and cylinders which demands less of the GPU. This approach allows the game to run on modest (but modern) hardware such as laptops. A modern browser is also required. Does not work on Android or iPhone, yet.
