Objective

Use a red ball to knock various "toys" off of a table for points. If the red ball goes off the table, you lose points. The level concludes successfully when all the toys are off of the table.

You don't control the ball directly but rather apply invisible forces to make the ball move. Gravity, friction, and momentum does the rest.

Beginner levels offer some aides to get you used to the game. For example, a magic fence is used to keep the ball on the table while allowing toys to fall through it. And, the levels are not timed.

As you advance to higher levels, there are more challenges: More and different toys. Wind will be introduced on some levels. Higher levels are timed.

Bonus points can be had for certain maneuvers on a toy. And, some toys have to be dislodged from the walls by hitting them with the red ball.

Hardware Requirements

Many 3d games require a beefy GPU. However, the live 3d Holy Balls game uses relatively simple toy patterns like blocks, cones, and cylinders which require less of the GPU. This approach allows the game to run on modest (but modern) hardware such as laptops. Doesn't work on iPhone, yet.

User actions while in the game

press the X key or click the Close button (upper right corner) to exit the game.

You push the ball around by holding down the left mouse button.

You can also use the Arrow keys or 4, 8, 6, 2 on the keypad to push the ball around.

Use the Space Bar or keypad 5 to bounce the ball.
