How to plat the Holy Balls Game

Objective

Use a ball to knock various toys onto the floor for points. However, if the ball falls on the floor, you lose points. When all the toys have fallen to the floor, the game moves to the next level. There are about ten levels per game. Eack level provides a different challenge.

How it works

In this game, you don't control the ball directly but rather apply invisible forces using your mouse to make the ball move. Gravity, friction, and momentum take care of the rest.

Beginner games provide some aides to get you familiar with the game. For example, a magic fence is used to keep the ball on the table while allowing toys to be pushed through it. The beginning games are not timed.

As you advance to harder games, there are more challenges: No more fences. More and different toys. Wind will be introduced on some games. Harder games are timed. And the countdown can sometimes be short.

Bonus points can be had for certain maneuvers on a toy. Some toys have to be dislodged from the walls by hitting them with the ball.

How to Play

Click on one of the games on the "Play" pane. This is a full screen game. The game ends when you hit the escape key or X key on the keyboard or click the close button. The game also ends when a timed level times out. If you lose your balls on a level, the game ends. Completing all levels of a game also ends the game. You can then play the same game or another game again.

When toys are dropped onto the table, some may fall off of the table without your assistance. You will get credit for them. On the other hand, when a ball falls off the table, it will cost you points.

Scoring

Each toy that hits the ground adds points. Some toys, such as the black disk, subtract points unless you've turned it white. If you get all of the toys on the ground before time runs out, you get bonus points for completing a level.

The scoreboard shows the points scored for the current level and the total score for the game.

Each toy that hits the ground adds points. Some toys, such as the black disk, subtract points unless you've turned the disk white. If you get all of the toys on the floor before time runs out, you get extra points for completing that level.

The Play pane shows the latest score for each game. If you login, I'll keep your scores in the cloud for subsequent sessions and also keep track of your highest score for each level.

User actions while in the game

Press the X key or click the Close button (upper right corner) to exit the game.

Push the ball around by holding down the left mouse button and moving the mouse.

You can also use the Arrow keys or 4, 8, 6, 2 on the keypad to push the ball around.

Use the Space Bar or keypad 5 to bounce the ball. The more you press it, the higher the ball goes.

In some cases, a toy could be hiding behind a barrier. Use the O key (for "overhead") if you need a quick look at the table from the top down.

Cheat Codes while in the game

Press the N key to go to the next level. If the next level is timed, the timer starts right away.

Press the R key to replay the same level.

If a ball does fall off the table, you might be able to recover it by using the space bar and mouse to bounce it back up as long as the ball doesn't reach the floor.

Hardware Requirements

Unlike many 3d games that require a beefy GPU, the Holy Balls game uses relatively simple toy patterns like blocks, cones, and cylinders which demands less of the GPU. This approach allows the game to run on modest (but modern) hardware such as laptops. A modern browser is also required. Does not work on Android or iPhone, yet.
