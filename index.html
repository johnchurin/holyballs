Welcome to the Holy Balls game

Objective

Use a red ball to knock various "toys" off of a table for points. As you advance to new levels, there are more challenges. Beginner levels offer some aides to get you used to the game. For example, a magic fence is used to keep the ball on the table while allowing toy to fall through it. Higher levels introduce wind that complicates play. Also, higher levels are timed.

Things to know before starting the game

Hardware Requirements

Many 3d games can require a beefy GPU. However, the live 3d Holy Balls game uses relatively simply toy pattern, like blocks, codes, cylinders, etc in order to allow the game to run on modest, but modern, hardware such as laptops.

Keyboard keys

G key to start a new game

N key to start a new level

Enter key to drop a new ball on the table.

Space bar to bounce the ball up.

Arrow key or 4, 8, 6, 2 on the keypad to push the ball around.

The mouse with the left button down also pushes the ball.
